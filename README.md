# Teacher Mobile App

A Flutter-based mobile application for teachers of the EduHard system.

## Features
- Teacher Authentication (Email/Password)
- Welcome Screen with personalized message

## Getting Started
1. Ensure you have Flutter installed.
2. Run `flutter pub get` in this directory.
3. Update the `_baseUrl` in `lib/login_page.dart` if your backend is hosted elsewhere.
4. Run `flutter run`.
